# GeoSketch · 几何画板

一个用 **Python + PySide6** 实现的交互式几何画板（Geometer's Sketchpad / GeoGebra 风格），
核心是一套**约束求值引擎 + 注册器插件架构**：拖动一个点，依赖它的所有图形（中点、交点、
等分点、角度、比例……）实时联动更新。

---

## ✨ 特性

**几何引擎**
- 依赖 DAG + 增量重算：创建顺序即拓扑序，拖动后只重算受影响的子树
- 级联删除：删一个点，过它的线段、相关交点/等分点一并清除
- 通用交点框架：求解器注册表，线段×线段、线段×圆、圆×圆、多边形×任意图形
- 磁吸吸附：屏幕恒定半径，随坐标系缩放自动换算世界半径
- JSON 序列化：存盘 / 读盘，按拓扑序重建

**内置工具**
| 工具 | 快捷键 | 说明 |
|------|:------:|------|
| 选择 | `V` | 拖动点、选中删除 |
| 点 | `P` | 自由点 / 对象吸附点 |
| 线段 | `S` | 两点定线段 |
| 圆 | `C` | 圆心 + 圆周点 |
| 交点 | `X` | 任意图形求交 |

**插件工具**（位于「工具」菜单，文本工具在左侧栏）
| 插件 | 快捷键 | 说明 |
|------|:------:|------|
| 多边形 | `G` | 正 3~8 边形 |
| 中点 | `M` | 两点连线中点（从动） |
| N 等分 | `D` | 两点连线 N 等分（2~12） |
| 直线 | `L` | 无限长直线 |
| 射线 | `Y` | 端点 + 方向 |
| 角度 | `A` | 三点测角，实时读数 |
| 比例 | `R` | 两线段长度比（最简分数，左上角 HUD） |
| 文本 | `T` | 可指定颜色/字号/锚定点 |

**界面**
- 左侧磨砂玻璃工具栏 + 右下缩放控件 + 悬浮删除按钮
- 四套主题一键切换：**纸白 / 墨夜 / 蓝图 / 黑板**（画布、网格、图标、菜单整体换肤）
- 完整坐标系：自适应网格、带箭头坐标轴、刻度数值
- [qtawesome](https://github.com/spyder-ide/qtawesome) 矢量图标

## 📦 安装

需要 **Python ≥ 3.9**（推荐 3.12）。

## bash
git clone https://github.com/GIMPISGOOD/geosketch.git
cd geosketch
pip install PySide6 qtawesome

## 基本操作
左键：使用当前工具绘制 / 选择
滚轮：以光标为锚点缩放
中键拖拽：平移画布
Delete：删除选中对象（级联）
Esc：取消进行中的操作
Ctrl+S / Ctrl+O：保存 / 打开（JSON）
